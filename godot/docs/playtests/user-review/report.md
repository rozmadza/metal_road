# Report

Пользовательский playtest Metal Road, 2026-09-21. Проверены требования последнего
брифа на текущей реализации Sprint 1 + Phase A. Полный vertical slice **не готов**.

## Что изменено

Проведён оконный playtest через X11/XTest: реальные клики, стрелки, Enter, Escape,
W/A/S/D, Space, R, F1. Игровые методы, здоровье, координаты и правила во время
теста не подменялись. Затем выполнен полный smoke-suite.

Это проверка существующей реализации, без перехода к разработке Phase B.

## Какие файлы добавлены

`docs/playtests/user-review/report.md`, `game.log`, скриншоты и `smoke-logs/`.
Временный драйвер мыши/клавиатуры находится в `/tmp/metal_user_qa.py`.

## Какие файлы изменены

Игровой код, сцены, Resource и настройки проекта не изменялись.
Громкость и fullscreen менялись через обычный UI. Проверен повторный запуск.

## Результаты tests

**17/17 smoke-тестов PASS**, exit 0. Результаты полного текущего набора записаны в `smoke-logs/`.
Сохранились известные предупреждения освобождения audio-ресурсов в части headless-тестов.
Оконная сессия запускалась на Godot 4.7.2 / GL Compatibility / Intel HD Graphics 4000.
В `game.log` нет runtime script errors. Проверка звуков по слуху и длительная
нагрузка с шестью машинами в этот playtest не входят.

После подтверждённого выхода и повторного запуска последнее тестовое окно
оказалось закрыто до заключительного снимка меню; причина по логу не установлена.
Это не объявляется воспроизведённым crash: в логе нет соответствующей ошибки.

## Найденные проблемы

### P1 — мешают основному игровому опыту

1. **HUD скрывает игрока при старте Survival.** Войти в Survival: машина в верхней
   левой области полностью находится под панелью 476×140. В Race панель перекрывает
   верхнюю прямую и часть стартовой позиции. Скриншоты 07/15/19.
   Требование «HUD не перекрывает карту» не выполнено; приоритет Phase B.
   Дополнительно F1: строка Debug overlay пересекается с заголовками модулей (кадр 12).
2. **Race ещё не Combat Race.** После езды, стрельбы и столкновений все модули 100%.
   Подтверждение аудитом: Game не регистрирует участников в combatants;
   Bullet выбирает цели из этой группы. Нет общего боевого участия Race, смерти,
   respawn/DNF. Это незавершённая Phase C, а не зависшие значения HUD.
3. **Race не имеет завершения.** Нет кругов, позиции, времени, финиша и результатов.
   Текущий заезд не позволяет выполнить цель «прийти первым».

### P2 — читаемость, обратная связь и незавершённые функции

4. **Машины очень малы относительно арены.** На 800×600 силуэты и направление
   различимы слабее трассеров; детали и мелкие стадии повреждений почти теряются.
   Новый арт меню заметно качественнее игрового окружения.
5. **Нет полноценного экрана результатов.** Survival даёт баннер и R/Esc, но нет
   kills/damage/time/Credits и кнопок Retry/Garage/Menu после результата.
6. **Garage — только осмотр.** Один Sport и один Machine Gun. Четыре модели, выбор,
   сравнение цены, покупка и upgrades отсутствуют; фазы D/F/G/H не выполнены.
7. **Настройки не переживают перезапуск.** Установлена громкость около 30%, она
   сохранялась при переходах по сценам, но после «ВЫХОД»/запуска снова 100%.
   Нет отдельных sliders Music/SFX/Engine и save_version/profile.
8. **Fullscreen сохраняет 4:3 с чёрными полосами.** На 1366×768 фактическое игровое
   поле остаётся 1024×768. Ранее отдельный wide viewport показывал лишь возможность
   компоновки, не реальную настройку aspect ratio окна. Не crash, но широкоформатный
   режим не использует весь экран. На checkbox заметен тесный отступ индикатора.
9. **Арена/трек остаются прототипными.** На арене сетка и простые прямоугольники;
   OilSpot, ExplosiveBarrel, radial/chain damage, pickups и environment art set нет.
10. **Destruction/VFX неполны.** Горящий wreck и живые модули видны. Отдельного
    взрыва, отлетающих частей и shake в текущей реализации нет. Аудит подтверждает
    старые пороги 75/50/25%, а новый бриф требует 70/40/15%.

### Наблюдение для балансировки

Боты способны быстро уничтожить друг друга; первый раунд завершился при небольшом
участии игрока и полном Body. Это допустимо для free-for-all, но требует проверки
длительности раунда и того, насколько победа ощущается заслуженной.

## Следующий этап

Phase A можно принять как визуальную основу меню с указанными ограничениями.
Следующий приоритет — Phase B: освободить игровое поле, перенести модули вниз вправо,
скорость вниз влево, оружие в центр, добавить hud_race_smoke на реальные изменения
Player. Затем Phase C: единое боевое участие, проверка попаданий/тарана/смерти,
политика восстановления после уничтожения и race_combat_smoke.
