# Phase D report

`RaceProgress` использует существующие длину, проекцию и финишную геометрию
Track. Последовательные контрольные четверти, достаточный пройденный путь и
пересечение финиша вперёд защищают от накрутки кругов. Три круга задаются
TrackConfig, вместе с параметрами проверки прогресса.

Game ведёт время, позиции, FINISHED/DNF, kills и фактически нанесённый урон.
Финиш/уничтожение игрока останавливают заезд и открывают RaceResults.
Кнопки: Заново / Гараж / Главное меню. Credits пока 0: экономика — Phase G.

21/21 smoke PASS: исходные 17 плюс HUD, combat, progress, finish.
`race_finish_smoke` проверяет в том числе результат из обработчика настоящей
летальной пули, восстановление после Retry и переходы в другие сцены.
Пули при завершении удаляются отложенно, чтобы не освобождать исполняемый Node.

Оконный прогон через InputMap, без телепортов/изменения HP: соло 3 круга
за 24,73 с; с ботами — 3 круга за 37,52 с, место 3/3, урон 100.
Есть также DNF-прогоны. Это автоматизированное вождение, а не ручной финиш.
Результаты финальной проверки мышью и ограничения: [report.md](report.md).
