# Metal Road — Phase A artwork

Generated specifically for the project with the built-in imagegen tool,
2026-09-21. Original generated PNGs copied unchanged into the repository.

- derby_background.png: industrial demolition derby key art, dark left UI area,
  armored coupe in foreground, red sliding car, fire, sparks and factory lights.
- metal_road_logo.png: separate transparent METAL / ROAD steel title, scratched
  bevels, bolts, amber hazard accents. All menu buttons remain native Godot UI.
- menu_overlay.gdshader: configurable darkening, left gradient and vignette.

No runtime network calls. Replace textures in MenuBackdrop/MainMenu scenes.
The original Sport texture from Sprint 1 is reused in Garage.
